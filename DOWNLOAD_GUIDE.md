# 📥 Complete Download Guide - EDA Agent

## Overview
All major features in the EDA Agent now support **downloading results** directly from the frontend!

---

## 🎯 Download Options by Feature

### 1. **📊 Dataset Download** (Dashboard)
**Location**: Main Dashboard page

**What you can download**:
- Original uploaded datasets
- Any dataset in your workspace

**How to use**:
1. Go to Dashboard (`/`)
2. Find your dataset card
3. Click the **"Download"** button (download icon)
4. File saves as the original filename

**API Endpoint**: `GET /api/download/{file_id}`

---

### 2. **🔧 Preprocessed Data Download** (Preprocess Panel)
**Location**: Analysis page → Preprocess tab

**What you can download**:
- Cleaned datasets after preprocessing
- Data with missing values handled
- Scaled/normalized data
- Encoded categorical variables
- Dimensionally reduced data
- SMOTE-balanced datasets

**How to use**:
1. Upload and open a dataset
2. Go to **Preprocess** tab
3. Configure preprocessing options:
   - Missing value handling (mean, median, KNN, iterative)
   - Outlier detection (IQR, Z-score, Isolation Forest)
   - Scaling (standard, minmax, robust)
   - Encoding (onehot, label, ordinal, frequency)
   - Dimensionality reduction (PCA, t-SNE, SVD, LDA)
   - SMOTE for imbalanced data
   - Polynomial features, binning
4. Click **"Apply Preprocessing"**
5. When successful, a green success box appears with **"Download"** button
6. Click **Download** to get the processed CSV

**Features**:
- ✅ Shows before/after shape comparison
- ✅ Shows new filename
- ✅ Immediate download after processing
- ✅ Downloads as CSV file

**API Endpoint**: `GET /api/download/{new_file_id}`

---

### 3. **📈 Generated Plots Download** (Multiple Locations)

#### A. **From Chat Panel** (AI-Generated Plots)
**Location**: Analysis page → Chat tab

**What you can download**:
- All plots generated by AI during chat
- Automatically saved after generation
- Includes smart auto-visualizations (8-12 plots)

**How to use**:
1. Go to **Chat** tab
2. Ask AI to generate plots:
   - "show me comprehensive visualizations"
   - "plot all relationships"
   - "visualize Age vs Fare"
3. Plots are automatically saved to database
4. Click **"Download Plots"** button at top of chat panel
5. Downloads as `ai_generated_plots_{file_id}.zip`

**What's included in ZIP**:
- All plots as numbered PNG files
- Descriptive filenames (e.g., "01_Histogram_Age.png")
- High-quality images (100 DPI)

#### B. **From Visualization Panel** (Saved Plots Viewer)
**Location**: Analysis page → Visualizations tab

**What you can download**:
- View all saved plots in a grid
- Download all plots as ZIP
- Download individual plots (right-click → Save image)

**How to use**:
1. Go to **Visualizations** tab
2. Scroll to **"Saved Plots"** section
3. Click **"View Saved Plots"** button
4. Options available:
   - **Download All**: Get all plots as ZIP file
   - **Delete All**: Clear all saved plots
   - **Individual view**: See each plot with metadata

**Features**:
- ✅ Grid layout with thumbnails
- ✅ Shows plot name, type, and timestamp
- ✅ Hover to enlarge
- ✅ Download count display

**API Endpoints**:
- `GET /api/plots/{file_id}` - List all saved plots
- `GET /api/plots/{file_id}/download` - Download as ZIP
- `DELETE /api/plots/{file_id}` - Delete all plots

## 🔧 Technical Details

### Download Mechanisms

**Frontend Implementation**:
```javascript
// Blob download pattern used everywhere
const response = await api.downloadFile(fileId);
const blob = new Blob([response.data]);
const url = window.URL.createObjectURL(blob);
const link = document.createElement('a');
link.href = url;
link.download = filename;
document.body.appendChild(link);
link.click();
document.body.removeChild(link);
window.URL.revokeObjectURL(url);
```

**Backend Endpoints**:
- File download: `FileResponse` with CSV/Excel
- Plot ZIP: `StreamingResponse` with `application/zip`
- Plot list: `JSONResponse` with base64 images

**File Naming Conventions**:
- Datasets: `{original_filename}.csv`
- Preprocessed: `preprocessed_{original_filename}.csv`
- Plot ZIPs: `plots_{file_id_prefix}.zip`
- Individual plots: `{number}_{plot_name}.png`

## ❓ FAQ

**Q: Where are plots saved?**
A: Plots are saved in the SQLite database (`PlotHistory` table) as base64-encoded PNG images.

**Q: Can I download plots generated in previous sessions?**
A: Yes! Plots persist across sessions. Use "View Saved Plots" to see all historical plots for a dataset.

**Q: What happens to the original dataset after preprocessing?**
A: Original data is never modified. Preprocessing creates a NEW dataset with a new file_id.

**Q: Can I download a single plot instead of all?**
A: Yes, in the Visualizations tab grid view, right-click any plot image and select "Save image as..."

**Q: How do I download merged datasets?**
A: Currently, merged datasets can be downloaded from the Dashboard after merge completes. Enhanced UI coming soon!

**Q: What format are downloaded plots?**
A: PNG format (Portable Network Graphics) at 100 DPI resolution, suitable for reports and presentations.
